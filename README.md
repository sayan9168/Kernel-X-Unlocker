# Kernel-X-Unlocker (Invention)

A sophisticated tool to interact with the Android Kernel via Termux without Root.

- **Kernel Exploit Integration:** Uses memory corruption techniques to gain temporary low-level access.
- **FBE Bypass Research:** Aiming to decrypt `/data` partition on Android 12+ devices.
- **Zero-Root Access:** No superuser permission required for scanning vulnerabilities.
